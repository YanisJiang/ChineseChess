# 中炮对屏风马：短谱网拼完整示范局

日期：2026-11-05  
状态：设计待审（实现前需用户确认本文件）

## 目标

让用户在陪练中从「中炮对屏风马」出发，通过**多段短谱接力**（而非一棵巨大单谱），能走出**完整一局结束**的体验，并验证是否与预想一致。

具体要求：

- 能分别走到 **红胜 / 黑胜 / 和棋** 三种终局。
- 谱名与文案**不剧透结果**。
- 关键一手可激起**多个方向**（谱内多选 + 接到不同后续短课）。
- 按**局面阶段**切课，不硬定每课手数。

## 非目标

- 不改转谱、一手进谱、人机搜索逻辑（除非衔接测试暴露硬 bug，再单开）。
- 不改 AI `openingBook.ts`（人机开局库与学棋短谱网无关）。
- 本轮不把其它开局族（顺炮、仙人指路等）扩成同等完整示范网。
- 示范着法以教学可走完为准，不追求职业最优。
- 不做模糊子力匹配；仍靠精确 FEN / 一手进谱衔接。

## 方案选型

采用 **阶段短谱网**：

- 开局课早分叉（成型后即可分计划）。
- 中/残拆成多段短谱；课 A 走完后的局面 = 课 B 的 `startFen`（或课 B 树内节点）。
- 谱内关键点挂 ≥2 选；不同选接到不同后续课。
- 红/黑/和是三条可走通路，不是三套标题剧透的平行「胜负示范课」。

未采用：三套少交叉的平行链（难「一手多方向」）；少课深叉到终局（违背「不要大棋谱」）。

## 课切分

| 段 | 典型内容 | 结束条件 |
|---|---|---|
| 开局 | 中炮→屏风成型，及早分叉（出车/打兵/挺兵等） | 成型或第一个计划选定 |
| 中局前段 | 兑子、占肋、挺兵争先 | 子力结构明显变化 |
| 中局后段 | 破士、沉车、子力入局 | 进入残局子力规模 |
| 残局 | 运子、兑净、杀势或重复/限着 | 将死 / 困毙 / 三次重复或自然限着和 |

每课仍是短树：主线若干手 + 1～2 个关键分叉。

## 衔接规则

1. 中残课继续用 `startFen`；开局课从初始局面出发。
2. 接力：上一课某分支终点局面的 FEN，必须能被下一课根或树内节点命中（现有 `fenIndex` / `lookupStudyFen` / 一手进谱）。
3. 同局面多课命中：沿用现有 `pickFenHit`（剩余着法多 > ply 深 > preferLineId > id）。
4. 历史匹配 `autoMatchStudyLine` 仍跳过带 `startFen` 的课——中残只靠局面命中，设计时必须保证终点 FEN 可挂上。

## 标题与文案

- 标题只写局面/手段（如「兑马后续挺兵」「中兵渡河」），禁止胜负/和棋结果词。
- `benefit` / `comment` 只讲计划（争先、兑子、固防），不暗示「通向胜利」。
- 改造现有 `mid-paoda-zhongbing`、`end-duima-tingbing` 等为网节点，而不是孤立短课。

## 三路终局

| 通路 | 终局形态（仅实现层，标题不写） |
|---|---|
| 红向 | 主攻线走到将死或困毙 |
| 黑向 | 另一分叉：反先/反击，黑将死或困毙 |
| 和向 | 再一分叉：兑净或可触发三次重复/自然限着判和 |

三条通路共用早期若干短课，在中局关键点分叉；不必对称等长，但每条都能「一局结束」。

## 验收

1. 陪练选中炮对屏风，沿主线与分叉能转谱续走，不因谱短过早掉人机（在网覆盖范围内）。
2. 在关键分叉换选，分别能摸到红终局、黑终局、和棋（引擎可判定的结果）。
3. 侧栏课名与谱内文案全程不剧透胜负。
4. 现有合法着/课数量相关测试通过；新增衔接与三路路径断言。

## 风险与回退

- 课数上涨，目录变长——用阶段标题区分。
- 示范着法教学编排，非职业最优。
- 漏接 FEN 会掉人机——实现时用脚本/单测锁关键衔接。
- 回退：对话注解标签；可整段回退谱数据文件。

## 实现顺序（概要）

1. 定一条可走完的红向示范着法序列，按阶段切成短谱并写衔接 FEN。
2. 在关键分叉点抽出黑向、和向，补后续短谱至终局。
3. 改造现有中炮打中兵 / 兑马后续挺兵等节点接入网。
4. 校验合法着 + 衔接命中 + 三路终局测试。
5. 打回退标签。
